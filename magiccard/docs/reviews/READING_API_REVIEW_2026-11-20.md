# 塔罗解读接口两轮自测

基线为父仓库提交 `6afde7b`。范围是 `POST /api/tarot/reading`、共享客户端挂载，以及用户从选题到收到解读的流程。验收依据见 [原始需求](../../REQUIREMENTS.md) 和 [设计](../DESIGN.md)。

## 第一轮 · 接口与需求

原有 3 项测试在基线上通过。另行构造请求复现了三处缺漏。

| 复现条件 | 修复与复测 |
| --- | --- |
| 宿主鉴权通过后，省略 Origin 或携带 cross-site 请求标记 | Worker 与精灵的同源写入规则对齐，两种请求均返回 403，模型调用次数为零。本机脚本省略 Origin 仍可请求。 |
| 模型正文以“我是薇拉，”开始 | 去除这一前缀和行动标签，保留后续建议。 |
| 对解读接口使用 GET | 返回 405，并在 Allow 响应头列出 POST。 |

`node --test magiccard/tests/reading.test.mjs` 修复后 4 项通过。覆盖主题与牌阵校验、来源校验、先鉴权再调用、无效回答返回可重试错误。另以主站实际 `createEnvAiClient` 和模拟 Workers AI 绑定运行 78 张牌 × 正逆两种方向的 156 组请求，逐组核对牌义，均通过。牌库为 22 张大牌、56 张小牌，各张的本地牌图和表演视频存在。

## 第二轮 · 浏览器流程

使用独立 Chrome 配置访问本机游戏。检查使用页面控件，从敲铃、选题、抽满三张、依次翻牌一直到收到回答。

| 环境 | 执行与结果 |
| --- | --- |
| 1280 × 800 桌面，正常动效 | 选择事业。三次翻牌各自展示本地牌义；玩家点解读前无模型请求。收到一次真实本机模型响应，页面正文与接口返回文本一致。 |
| 390 × 844 触控模拟，减少动态效果 | 选择姻缘。让第一次请求返回 503 后点重试，两次请求载荷完全相同。第二次模拟成功响应后正文显示。 |
| 推理期间重开 | 暂停响应并点击重来，确认请求信号已中止。放行旧响应后仍在新局选题页，旧正文为空。 |

两种尺寸均无文档横向溢出，整局无页面脚本异常。重新抽牌清空结果，刷新回到首页，localStorage 和 sessionStorage 为空。默认本机端口 8786 已重新加载修复版本，推理服务健康检查通过。

本轮未发现其余接口或解读流程缺陷。手机使用浏览器模拟；物理设备帧率与线上 Worker 的实际推理效果未验证。主站集成与部署留待接收阶段。
