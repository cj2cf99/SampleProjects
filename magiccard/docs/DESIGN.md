## 同一间房的两段距离

初入房间时，薇拉在左侧窗和座椅之间活动。可以敲右侧椭圆桌上的铃，也可以陪她拨亮灯芯、去窗前看星、转动星仪，或留一枝窗边的薰衣草。选过的花会出现在近景桌边，她接续刚才一起做过的事来问候。这段记忆只保留在当前页面。走路用 48 张画格表现双脚交替支撑和摆动。一个完整步态周期历时 1.8 秒，地面位移按实际显示高度折算。星仪内环 2.4 秒、72 帧，擦灯 3.6 秒、90 帧。

| 时刻 | 玩家可做的事 | 薇拉与牌桌的反馈 |
| --- | --- | --- |
| 入座 | 选择姻缘、前路或事业 | 问句下方直接呈现选项，桌上留空 |
| 选牌 | 从七张候选牌里抽三张 | 她逐张发牌到桌上，接住玩家选的牌，略微点头，再把牌送回对应牌位 |
| 翻牌 | 依次点来处、当下、下一步 | 牌面入场，展示本地正逆位、关键词及含义，已揭晓的牌可回看 |
| 解读 | 全部翻开后听她回答 | 她收回同一组三张牌，按原方向持在指间。模型返回后把牌放回桌上，结果区仅显示建议正文及一项具体行动 |
| 重来 | 开启下一局 | 清空本局并回到选题，保留当前页面内选定的牌背 |

手机首页有专门的竖幅房间画和物件触点。入座后上方保留薇拉和对白，下方牌桌独立滚动，查看牌义或长回答时仍可看到人物。短屏缩短上下间距，优先保住人物双手、三张牌和下一步操作。桌面采用左侧人物与右侧牌桌的并置构图。

敲铃时，步行中的薇拉在双脚着地时换向，从窗边走回同一把固定座椅。入座由转身、寻椅、屈膝、承重坐稳及抬手迎客五组原画组成，每组五张。根据实际朝向选取转身起点。人物一刻只绘制一张画格，椅子单独绘制。镜头在承重完成后推近，迎客立绘和最后一帧使用同一幅画、同一个裁框。减少动态效果或过渡素材加载失败时直接进入选题。

入座后从玩家一侧看同一张桌，人物的目光和手在桌沿上方。选牌时仅牌桌一侧渐变为蓝绒桌面的俯视画。两种视角共用牌位和操作状态，飞牌按当前手与目标的实际位置走弧线。解读以本局问题为标题，她稍微靠近，再直接作答。

桌边近景按迎客、发牌、审视、回答分别制作底画与手臂层，指尖遮挡叠在手中牌上。手势围绕各自支点转动。飞牌从实测的当前手牌和目标牌位取起止坐标，重开会清除在途动画。系统启用减少动态效果时直接呈现落位结果。

## 牌组与动作

22 张大阿卡那加四组各 14 张小阿卡那，每张有正逆位。随机洗牌后取七张候选，不放回。22 张大牌与 16 张宫廷牌按头部、手臂、道具或画中主体单独切层，修补被遮背景，以固定支点转动和平移合成。40 张数字牌以对应花色排布一至十个独立图案。杯、剑、杖和星币按各自图案编排入场或周期动作。隐士提灯跟随手部，再围绕灯柄轻摆。

翻牌时按需加载 320×320、24 fps 无声短片。开头 1.5 秒为入场，之后每 9–13 秒完成一轮待机与特殊动作。循环跳过入场，逆位随整个牌面旋转。减少动态效果、资源失败时仍可读静态牌与牌义。星轨牌背有环形流光，暮玫的花心明暗交替，月森有萤光浮动。场景中擦灯的手和布也使用独立刚性图层。

## 数据与接口

原生 HTML/CSS/JS 和 Node 本机 HTTP 服务。所有当前牌位、正逆位、选题与设置只存在内存。前端向同源接口提交主题和三张牌的编号、方向。服务端校验唯一性，按牌位查本地牌义，发送给配置的模型，通过 JSON 返回正文。重来中止进行中的请求，失败可保留牌阵重试。无数据库、历史记录或账号。兼容接口与启动配置见 [运行说明](../README.md)。

本页取代早期设计中的 22 张限定、复制提示词及局部形变方案。前期复核保存在 `docs/reviews/`。
