## 实际验证

- `node --check` 验证 `motion.js`、`roll.js`。临时 Node VM 脚本用固定种子生成 5,000 组落点，检查六组画布宽高比、双画面的保守外接间距和末骰边缘余量。5,000 组均使用连续采样。四骰测试在 660×458 像素坐标中覆盖 4,666 个不同落点。有限重试全部用尽时才使用已验证的备用位置，该测试未触发备用位置。
- 数值复测 264 条末骰临界轨迹，覆盖 D3–D8 的各个点数、两种视图、方向和结局。验证前滚越过临界角，倒回在临界前反向，最后准确归位。
- 隔离 Chrome 实测 1440、390、320 像素宽度、普通和减少动态效果。用同一组 `4 + 7 + 8 + 3 = 22` 复现两个不同坐标组合。核对两组结果同步。保存 `randomCheck-material-motion.mp4` 及桌面、手机截图，临时浏览器脚本已清理。
- 本地复核通过。实体手机、跨浏览器和用户实际观感待确认。
