# 角色动作设计与 GIF 生成交接参考

**状态为参考稿。** 本交接包和「侧耳聆听」样例仅供云端设计、制作与问题排查参考。正式版本以云端后续制作并经用户验收的版本为准。

以 `reference/original.png` 为角色的外观和站姿基准，设计可在屏幕侧边播放的全身动作。每套动作要说清动作内容和适用场景，并提供进入、循环、退出的关键帧与一支短 GIF。`example/side-listening-reference.gif` 展示了用户确认可行的一种实现。

## 用户要求与已确认调整

- 原始目标是把同一角色的基准图用作整段首尾，设计进入、循环、退出三段。默认进入 1 秒，循环共 4 秒、重复 2 次，退出 1 秒，总长 6 秒。每轮循环的首尾引用同一帧。
- 每张 PNG 和 GIF 画布均为 **400 × 600 px** 竖版。沿用原图的脸型、发型、发饰、服装、体形和头身比例。角色全身持续入画，四边以约 10 px 为安全下限。保持镜头、人物整体比例和脚底锚点稳定，统一使用纯绿背景。本角色样例的标准绿为 `#02F903`。
- 默认角色在屏幕右侧、朝画面左边。放到屏幕左侧时，以脚底锚点为基准水平镜像角色整层，站位和界面元素由外层独立控制。
- 后续确认每段各有 **两张中间关键帧**，并用用户基准图与这些姿势合成 GIF。头部使用同一比例，已确认可用原图头部做等比例点头。每套作品共 **8 张独立 PNG**：基准 1 张、循环共用 1 张、三段中间帧各 2 张。
- 动作之间要有明确差别，尤其是用途、主动作和轮廓。两张中间帧应体现各自的动作进度。整段首尾、循环接缝及两轮循环内容按时序要求复用。

## 生成顺序

1. **先定动作和用途。** 用一句话说明看到什么、在什么场景触发。写出三段各两张中间姿势的变化、循环起止姿势、动作主导部位和固定部位。同批有多个动作时，先比对姿势和用途，把重复设想换成有清楚辨识度的动作。
2. **先做基准和循环共用帧。** 使用原图等比例导出基准 PNG，统一画布与绿底。明确脚底锚点，做出循环起止共同姿势。整体首尾直接引用基准文件，循环各接缝直接引用循环共用文件。
3. **补齐六张中间帧。** 给生成工具提供原图、需要时附上两侧的相邻姿势。描述要移动的部位、朝向和目标姿势，并锁定镜头、角色比例和未参与动作的部位。优先复用稳定图层，特别是头部、承重脚和静止衣饰。表情需要变化时，尽量局部调整眼睑、眉或嘴。
4. **校准后再合成。** 按进入、循环两次、退出排时间线。平滑段用固定比例的图层位移或旋转连接关键姿势。对手与脸、袖口与手臂等遮挡变化明显的部位，先试播并逐帧检查。自动补间出现重影时，可回到清晰的关键姿势，或用独立图层重做该段。接缝共享同一个时间点，避免重复帧造成额外停顿。
5. **导出并验收实际 GIF。** 用统一调色板保留指定绿底，检查编码后背景颜色、尺寸、总时长和帧序。解码核对整段首尾一致、两轮循环相同、接缝完整。快速看整段，再逐帧检查极端姿势、发簪、丝带、手指、鞋跟和边缘留白。

## 校准原则

| 校准对象 | 检查和修正方法 |
| --- | --- |
| 头部与头身比例 | 先把各帧按脚底锚点对齐，再放大查看额饰、眼距、脸部轮廓和发髻。直立姿势优先直接共用原图头部。点头以颈部为轴做等比例旋转和必要的小幅位移。比较随头移动的标志点间距，避免只用旋转后的外接矩形判断大小。 |
| 支撑与重心 | 承重脚随站姿固定。原地动作检查鞋底坐标、脚印位置和腿长。确需踏步时，在动作设计里标出换脚和落地点，再按落地帧校准。 |
| 手势和遮挡 | 展开检查手从哪里来、到哪里去，以及每个中间姿势是否读得出来。手靠近耳朵时保留抬手图层在前，保证面部、耳饰和衣袖之间的遮挡连续。 |
| 背景和轮廓 | 使用同一帧尺寸和同一个纯绿。逐帧测前景离四边的最小距离，特别检查抬手最高点和发饰最外点。复核 GIF 解码结果，防止缩放或调色板转换带来绿底偏色、边缘晃动。 |
| 速度与接缝 | 核对进入、每轮循环、退出的实际时长。用同一文件保证接缝姿势一致，再看动作速度是否突然跳变、回位是否停顿过久。 |

## 收到反馈后的处理方法

1. 把用户描述变成可观察的检查。比如「头部大小明显出现跳跃了」对应头部轮廓和标志点间距随帧变化。保留已确认的场景、动作结构、时间和构图。
2. 先在成品中复现，再按**生成关键帧 → 合成图层 → GIF 编码**逐层对照。把同一区域按同一锚点并排放大，定位第一次出现差异的阶段。
3. 从产生问题的地方做最小修正。修完重导并复查相关帧及相邻接缝。复核发现新问题时先说明现象和影响，再在原授权范围内修正。最多做三轮，达到通过条件便停止。有残留问题时写明具体表现和证据。
4. 回交新版本、实际检查结果和仍需用户看效果的地方。涉及更换动作、用途或放宽已确认限制时，先说明取舍并等用户决定。

### 本次实例

| 问题来源 | 怎么定位 | 怎么解决和确认 |
| --- | --- | --- |
| 用户反馈「头部大小明显出现跳跃了」 | 并排放大八张头部裁切，发现点头和抬眼帧的脸部轮廓、发髻被重新绘制。随后比较 GIF 解码帧，发现一次按 DPI 重采样还造成了细微闪动。 | 用原图同一头部和表情合成各直立姿势。两轮点头都绕颈部做固定比例旋转，保留耳旁的手在前。导出统一 RGB 像素格式，避免按 DPI 重采样。逐帧复核直立头部的上半区域、两轮循环画面和整段首尾。用户确认修正版可行。 |
| 自检发现抬手补间重影 | 对照进段的中间帧，看到自动运动补间使手和袖口短时间重叠成双。 | 进段与退出用清晰的关键姿势。循环点头用同一图层连续转动，单独复核手在耳旁的遮挡。 |
| 自检发现退出姿势与循环太接近 | 退出中间帧的手仍靠耳，连续看难以分辨开始收手的时刻。 | 退出第一帧把手降到胸前，第二帧落到腹前接近交叠。复核收手路径与进入路径的轮廓差异。 |

## 参考样例 侧耳聆听

用于语音输入已开启、等待用户开口时的角色提示。她面朝左，抬手至耳侧，两次轻点头，再收手回到原图站姿。下表时间为已确认 GIF 的实际关键姿势位置，其他动作可在同样的三段时长内调整中间帧位置。

| 时间 | `example/keyframes/` 中的文件 | 姿势 |
| --- | --- | --- |
| 0 秒、5.92 秒至 6 秒 | `00-base.png` | 原图基准。双手交叠，交叉站姿。 |
| 0.32 秒 | `01-enter-lift-waist.png` | 抬手经过腰间。 |
| 0.68 秒 | `02-enter-lift-shoulder.png` | 指尖抬至肩侧，正向耳边靠近。 |
| 1、3、5 秒 | `03-loop-seam.png` | 拢手侧耳，头直立。 |
| 1.84、3.84 秒 | `04-loop-nod.png` | 点头到最低处，发饰和眼睛随固定比例头部转动。 |
| 2.36、4.36 秒 | `05-loop-recover.png` | 抬头回位经过中间姿势，仍保持侧耳。 |
| 5.32 秒 | `06-exit-hand-to-chest.png` | 手从耳旁降到胸前。 |
| 5.68 秒 | `07-exit-hands-settle.png` | 手落到腹前，接近原图交叠姿势。 |

样例 GIF 每次播放 6 秒，预览自动重播整段。已解码检查 107 帧，尺寸和绿色背景符合要求，最小边距为 24 px。两轮循环逐帧一致，整段首尾一致。

## 每套动作交付

- 动作名称、用途、三段动作说明和关键帧时间表。
- 从原始基准出发的 8 张独立 PNG 和一支 6 秒 GIF。
- 简要验收记录，包括实际尺寸、播放时长、边距、首尾和循环接缝，以及仍需人工确认的表现。
